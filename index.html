เชื่อมต่อ Google Sheets API (Google Apps Script)

นำ Web App URL ที่ได้จากการเชื่อมต่อ Google Apps Script มาวางเพื่อซิงค์ข้อมูลจริงไปยัง Google Sheets ของคุณ

สลับโหมดการทำงาน:

• หากช่อง URL เป็นค่าว่าง ระบบจะทำงานในโหมด Mock Data (ทดลองใช้ฟรี)

• เมื่อใส่ URL แล้ว ระบบจะดึงและบันทึกข้อมูลเข้า Google Sheets โดยอัตโนมัติ
